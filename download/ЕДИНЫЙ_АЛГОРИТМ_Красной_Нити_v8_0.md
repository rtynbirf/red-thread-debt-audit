| Слой | Формула | Уточнение v8.0 |
|---|---|---|
| Кольцо, ρ=0 | сток = SH·G | **G = ∫P(R>τ)(1+i)^τ dτ замкнуто: P(R>τ)=1−τ·ln2/30 (τ≤30), (60−τ−τ·ln(60/τ))/30 (30<τ<60); R = V·W, V~U(30,60), W~U(0,1)** |
| Кольцо, уровень | D/Y = G·σ_flow | **измерен дренаж φ_G = 0.71–0.72 (стабилен на двух семенах) — промежуточные погашения срезают ~30% простого стока** |
| Кольцо, зона ρ∈[0.05, 0.25] | max(exp, пол) | **6/6 на seed=23 по замороженным критериям v7 — промах v7 (seed=11, ρ=0.1) не воспроизвёлся: локальная аномалия ветки, не дефект закона** |

## 3. Strict-столбец рецепта v0.7 (задание (3), из R10)

Правило рецепта: **каждый реестр операторов выходит в двух версиях — номинальной и строгой**; спуф-окна предрегистрируются ДО вычислений по документированному неплатежу; полоса шума — формульные перцентили контроля (v0.6, правило E10); промах инструмента ≠ промах данных (E12); при сшивке корпусов сверяется семантика столбцов по контрольной строке (E13). Первое применение: матрица R10 (230 строк, DebtService strict, Σie-спуф = 5.4% потока против strict-штрафа коллеги −37.5% r_marg).

## 4. Слои доказательности

- **FACT:** два порт-якоря бит в бит; λ(ρ=0, seed=11) воспроизведён бит в бит; φ_G ≈ 0.71 на двух независимых семенах; 6/6-переносимость по замороженным критериям.
- **CALCULATED:** λ_A(23)=4.361519, m(23)=0.020462; η-таблицы; G=72.36; SR=51.8/51.7; σ_flow=0.155/0.151; дрейф-промахи −0.311/−0.630.
- **MODEL:** двухкомпонентный закон v7 (третье семя, 6/6 вне выборки); G-механика пола (направление и структура подтверждены, количественно требует члена дренажа); дренаж = промежуточные погашения (гипотеза механизма — v9.0).
- **UNKNOWN:** точная форма переходной зоны при ρ∈[0.05,0.2] (E14: калибровать точкой внутри зоны или формой с насыщением); аналитический член дренажа; λ25-метрика vs уровень D/Y в полу (связь не выведена).
