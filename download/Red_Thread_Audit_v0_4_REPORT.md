## 0. Что исполняется и почему

В трёх документах раунда ПОЛИМАТ объявил четыре задачи и не исполнил ни одной машинно: (α) **REDTHREAD v0.4 PARAMETER IDENTIFICATION** — «для каждой территории построить один и тот же вектор θ… вычислить Δ» («Первый удар», §10 конца); (β) **AUDIT v0.4 «РАСКРЫТИЕ ПЕРИМЕТРА»** — «слоёный долг… и прогнать одинаковый граф переходов» (там же, §10); (γ) **R7 INVARIANCE TEST** — «единая матрица узел × переход × параметр × источник × confidence для РФ/США/КНР/ЕС и Δ между четырьмя реальными графами» (там же, §R7); (δ) **walk-forward backtest 2020→2026** — «модель должна предсказывать следующий год только из данных, доступных на предыдущий год» («ОТЧЁТ v0.2», финал). Исполнены все четыре, одним прогоном, на неизменном графе v0.1:

```
d[t+1] = ((1+r)/(1+g)) · d[t] − pb,     r_real[t] = ((1+ie[t]/d[t−1])/(1+π[t]/100)) − 1
```

Требование Полимата «IMF нельзя использовать одновременно как территорию и как единственного арбитра» принято как дизайн: территория — серии API (класс A, файлы сохранены), арбитр — внутренняя согласованность замороженного оператора и независимая серия WB для частного слоя; C-якоря (цифры Полимата с IMF-ссылками) остаются классом C до независимой проверки.

Наивная инерция стока бьёт замороженный граф везде, включая РФ. Требование Полимата исполнено, и ответ отрицательный: **на горизонте одного шага граф не имеет прогностической силы**. Его сила — обратная: разложение уже случившегося (SFA ниже) и сценарное перенесение θ. Прогноз требует члена, которого нет в графе и нет в API — маржинальной ставки.

## 6. Недостающий член оператора измерен: P2 ПОДТВЕРЖДЕНА во всех трёх частях

- **P2a ✓**: r_imp − g для КНР = **−4.07 п.п.** < 0 (единственная территория, где сток растёт быстрее процента).
- **P2b ✓**: РФ, номинальная маржинально-неявная разрыв: **14.55% (ключевая, ЦБ, C-якорь Полимата) − 5.06% (неявная на стоке) = +9.49 п.п.** Старый долг обслуживается по 5%, новый выпускается по 14.5% — вот член, который граф теряет и который IMF-путь 19.1→29.1 уже содержит.
- **P2c ✓**: США, поток процентов: ie 2.66% ВВП (2021) → **3.95% (2024), ×1.48 за три года** — репрайсинг виден не в ставке, а в счёте.

Закон раунда: **неявная ставка — заднее зеркало; репрайсинг r_gap(t) = r_marg(t) − r_imp(t) — самостоятельный член динамики долга, и именно его отсутствие объясняет все три отрицательных вердикта (P1, P1b, P5) сразу.**

## 9. Законы раунда

1. **Закон запаздывающей ставки**: неявная ставка на стоке не предсказывает — она объясняет. Без члена r_marg граф даёт систематический розовый сдвиг (все DIFF_op отрицательны, −12.9..−21.2) и проигрывает наиву. Измеренный член: РФ +9.49 п.п., США ×1.48 в потоке за три года.
2. **Закон периметра**: раскол 37.6 п.п. между двумя честными линейными контролями одной страны (КНР) доказывает, что D — не переменная, а семейство переменных; перенос θ через периметр не работает (−25.1) — у периметра своя динамика.
3. **Закон российской нагрузки**: частное/ядро ×3.31 — максимум из четырёх; суверенного долга мало потому, что машина записи переключила носителя (корпорат + домохозяйства), а не потому, что машина выключена; и сама запись частного слоя РФ оборвана в 2021.
4. **Ревердикт R7**: инвариантность одного графа с разными коэффициентами передачи на измеримых признаках НЕ подтверждена (США-хаб, РФ-экстремум); критерий Полимата Δ→0 на разных оболочках требует признаков, которых нет в API (держатели, сроки, маржинальная ставка).

## 11. Что этот документ не утверждает

Не доказано существование единой мировой машины и не опровергнуто — R7 на семи признаках дал «не установлен»; C-якоря Полимата не переврены и потому не являются фактами этого прогона; скоупы WEO для четырёх территорий не идентичны по юридическому составу (общее правительство США ≠ федеральный и т.п.) — это само и есть периметр-проблема; прогностической силы у замороженного графа нет (P5), и никто из нас не должен цитировать его траектории 2026–2031 как прогноз.
