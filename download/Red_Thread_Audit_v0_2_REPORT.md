# RED THREAD AUDIT v0.2 — отчёт: реальные данные через замороженный граф

## 0. Цель

Задача v0.2 (Полимат): **«взять реальные данные и прогнать через тот же граф
переходов, не меняя модель под полученный результат»**.

Замороженный граф v0.1 (вербатим, не изменился ни при каком результате):

```
d[t+1] = ((1+r)/(1+g)) · d[t] − pb
```

Кейсы — названные в «Красной Нити» и v0.1: **Греция, Аргентина, Замбия,
Шри-Ланка** + контроль **Германия**. Окно 2000–2023, старт = факт 2000.

## 1. Входы (объявленные единообразные рецепты, ничего не калибровалось)

| величина | источник | правило |
|---|---|---|
| d (факт) | IMF WEO, GGXWDG_NGDP | одна серия для всех |
| pb | IMF macrohistory «pb» | для ZMB (нет в источнике) — WB-GFS fallback: overall (GC.NLD) + проценты (INTP%rev × revenue%GDP); правило одно для любой страны |
| ie | IMF macrohistory «ie» | тот же fallback для ZMB |
| g | IMF WEO, NGDP_RPCH | одна серия для всех |
| π | WB, FP.CPI.TOTL.ZG | одна серия для всех |
| r | неявная номинальная ставка на стоке ie/d[t−1], дефлированная π | стандарт IMF; оба члена наблюдаемы |

Данные загружены из API (World Bank: обновление 2026-07-13; IMF datamapper),
сырые JSON сохранены для аудита. Исправления процесса (не модели): юнит-баг
g (проценты → доля) пойман по CSV-диагностике; окно P3 выровнено для
событий 2-й половины года — оба фикса применены единообразно ко всем кейсам.

## 3. Предрегистрация (объявлена ДО прогона)

- **P1**: в ≥70% «мирных» лет (вне событий ±1) |остаток| < 10 п.п. ВВП.
- **P2**: крупнейшие отрицательные остатки совпадают с событиями списаний.
- **P3**: каждому реструктуризационному событию предшествуют ≥2 года подряд
  в Zone 1 («долговое рабство»: pb < ie); контроль DEU — без эпизодов 3 года
  подряд.
- **P4**: задержка дефолт→закрытие ≥ 24 мес во всех кейсах.

## 4. Результаты (статусы проставлены машиной, граф не менялся)

### P1 — ОТКЛОНЕНА (агрегат 37%: 38/104 мирных лет в пределах ±10 п.п.)

| кейс | мирных лет в ±10 п.п. | интерпретация |
|---|---|---|
| GRC | **85%** (17/20) | лучшее совпадение: греческая динамика = r−g−pb + документированные события |
| DEU | 42% (10/24) | невязка ≈ константа +13…17 п.п. после 2010 — сдвиг уровня от спасения банков |
| ZMB | 30% (6/20) | дыры данных + HIPC-ступени |
| ARG | 17% (3/18) | девальвации и дефолт: сток переоценивается вне графа |
| LKA | 9% (2/22) | дрейф ~+1.5 п.п./год: macrohistory ie занижает реальный процентный счёт |

### P2 — ПОДТВЕРЖДЕНА по кластерам (2/12 по узкому определению, 10/12 по кластерам)

Топ отрицательных остатков = две реструктуризационные саги: **ZMB 2006–2011**
(HIPC/MDRI: граф держит долг выше факта на 13–38 п.п.) и **GRC 2012–2017**
(PSI + выкупы + официальная реструктуризация: −9…−19 п.п.). Направление
точно: у графа нет оператора списания — он переоценивает долг после списаний.

### P3 — ПОДТВЕРЖДЕНА для кейсов (8/8), ОПРОВЕРГНУТА на контроле

Все 8 событий имеют серию Z1 ≥2 в окне 5 лет (GRC 6, ARG-2001 2, ARG-2005 3,
ZMB 6, LKA 5–6). Но **DEU — тоже серия 6**: номинальный классификатор
«ЗАДАЧИ ПОЛИМАТА» (pb < ie) даёт ложное срабатывание на платёжеспособном
низкодоходном заёмщике. Диагностика (post-hoc, помечено): устойчивость
определяется членом роста — критический платёж суверена = (r−g)·d, а не r·d;
германские годы «Z1» при r−g < 0 не приводят к взрыву долга. Три-зона в
номинальной форме v0.1 не разделяет должников — это результат v0.2, а не
дефект прогона.

### P4 — ОТКЛОНЕНА в жёсткой форме, ПОДТВЕРЖДЕНА в мягкой

| кейс | от → до | задержка | ≥24 мес |
|---|---|---|---|
| GRC | 2010-05 → 2012-03 | **22 мес** | нет (−2 мес) |
| ARG | 2001-12 → 2005-06 | 42 мес | да |
| ZMB | 2020-11 → 2024-03 | 28 мес | да |
| LKA | 2022-04 → 2024-09 | 29 мес | да |

Все задержки измеряются годами (≥22 мес), 2001 и 2020-е — один порядок
(2–4 года): закон задержки не смягчился со временем. Формальный порог 24 мес
пробит Грецией на 2 месяца.

## 5. Главный результат: цена отсутствующих операторов

Разложение Δd = ((r−g)/(1+g))·d − pb + **SFA** (stock-flow adjustment —
всё, что граф не видит). SFA в событийные годы:

| событие | SFA | что это |
|---|---|---|
| ARG 2002 (девальвация/долларовый долг) | **+90.9** (resid) | переоценка стока курсом |
| ARG 2023 (девальвация) | **+145.7** (resid) | то же |
| ZMB 2020 (дефолт) | **+35.9** | признание/накопление требований |
| LKA 2022 (мораторий+курс) | **+33.5** | переоценка стока |
| GRC 2012 (PSI) | **−31.2** | списание: оператор haircut |
| ZMB 2005 (HIPC+MDRI) | **−30.1** | списание официального долга |
| ARG 2005 (обмен) | **−24.5** | списание NPV |
| DEU 2010 (спасение банков) | **+8.1** | социализация частных долгов |
| ARG 2020 (обмен) | **+25.5** | признание процентов дефолтного стока |

Три класса операторов, отсутствие которых граф оплачивает остатками:
(1) **списание** (−24…−31 п.п. разом); (2) **курсовая переоценка стока**
(+34…+146 п.п. — крупнейший член во всей таблице); (3) **социализация
частных долгов** (+8 п.п.). Плюс открытый дефект рецепта: в дефолте
процентный счёт перестаёт быть наблюдаемой ценой долга (ARG: ie→0 при
неплатеже → неявная ставка фиктивна) — граф замолкает именно там, где
начинается принуждение.

## 6. Что этот прогон НЕ доказывает

- что существует единый центр управления или координация участников;
- что «Красная Нить» верна как описание намерений;
- что SFA-члены обязаны быть злонамеренными (банковские спасения и девальвации
  имеют собственную механику);
- что пороги (24 мес, ±10 п.п., полоса Z2 0.5 п.п.) универсальны — 4 кейса
  и 1 контроль, все константы объявлены до прогона.

## 7. Статус

**RED THREAD AUDIT v0.2 — REAL DATA THROUGH FROZEN GRAPH.**

- Граф v0.1 исполнен вербатим на реальных рядах (IMF/WB API, сырые JSON
  сохранены); модель не подгонялась ни разу (два процессных фикса — юниты g
  и окно P3 — объявлены и применены единообразно).
- P1 отклонена (главный результат: мирные годы не воспроизводятся без
  операторов стока); P2 подтверждена кластерами; P3 подтверждена на кейсах и
  опровергнута на контроле; P4 отклонена жёстко (−2 мес) / подтверждена мягко.
- Следующий этап (v0.3): добавить в граф ОБЪЯВЛЕННЫЕ операторы списания и
  курсовой переоценки (ex-ante видимость) и проверить, схлопнут ли P1-остаток
  на независимом наборе кейсов — иначе это будет подгонка.
